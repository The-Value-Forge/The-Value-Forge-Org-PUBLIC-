WHY THIS IS A PARTIAL AND NOT INLINE It started life inline in `_default/single.html`, which silently did nothing for the Monthly — `layouts/monthly/single.html` exists and takes precedence, so the flagship, the one page most in need of this, was the one page that never got it. The regex tests all passed; only rendering the real page showed the zero. Two templates render pipeline prose, so the transform lives in one place they both call. WHAT IT FIXES The translator emits domain names, cross-domain claims and editorial closers all as bold paragraphs, so they render identically and the page reads as a wall. CSS cannot help — it cannot match on text. FAILURE MODE, BY DESIGN Every rule below matches an exact, closed vocabulary. A renamed heading, a sixth domain, or a pattern link landing inside the bold simply stops matching: the page degrades to its previous appearance rather than breaking. A lost section head is visible; mangled markup would not be. */}} {{/* THE TRANSFORM CHAIN, IN ORDER. Lifting the flag out of the sentence is the whole point for the monthly: a bold full sentence reads as a heading it is not, and re-setting a sentence in a label register would be worse than leaving it alone. */}} {{- if or (eq .Section "synthesis") (eq .Section "monthly") -}} {{- $reg := "/patterns/" | relURL -}} {{/* THE VOCABULARY MOVED, AND THESE RULES DID NOT FOLLOW IT. Every rule below matched the old spelling only, so from the 28 August batch onward the flag stopped being a flag and became a bracketed token sitting in the prose — the same failure the partial was written to fix, reintroduced by a rename.
